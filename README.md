# StreetViewVR

Веб-сервис для просмотра уличных панорам Mapillary в режиме виртуальной реальности через Google Cardboard и аналогичные держатели для смартфона.

Панорама отображается на внутренней стороне сферы, а экран телефона разделяется на два изображения — по одному для каждого глаза. Ориентация телефона используется для поворота камеры.

Можно попробовать здесь – <https://nikitagut.github.io/StreetViewVR>

## Возможности

- просмотр панорам Mapillary в стереорежиме;
- режим без очков с управлением гироскопом или пальцем;
- поиск начального места через OpenStreetMap Nominatim;
- карта OpenStreetMap с точками панорам Mapillary;
- выбор следующей панорамы направлением взгляда;
- масштабирование и перемещение карты;
- закрытие карты крестиком в правом верхнем углу;
- настройка сближения изображений для разных VR-очков;
- резервная обработка `deviceorientationabsolute` для устройств, где обычное событие ориентации работает некорректно;
- встроенная диагностика событий ориентации и движения.

## Быстрый запуск

Проект не требует сборки и зависимостей — это статическая HTML-страница.

### Локально

Из корневой папки проекта запусти любой статический HTTP-сервер, например:

```bash
python3 -m http.server 8080
```

Затем открой <http://localhost:8080/>.

Для проверки гироскопа на телефоне нужен HTTPS. `localhost` подходит для разработки на компьютере, но обычный адрес локальной сети вида `http://192.168.x.x:8080` может блокироваться браузером.

### GitHub Pages

1. Создай репозиторий и загрузи `index.html`.
2. Открой **Settings → Pages**.
3. В разделе **Build and deployment** выбери публикацию из ветки, обычно `main`, папка `/ (root)`.
4. Открой выданный адрес вида:

   `https://<username>.github.io/<repository>/`

Открывай страницу непосредственно в Chrome или Safari, а не во встроенном браузере мессенджера.

## Использование

1. Введи место поиска или оставь значение по умолчанию.
2. Для Cardboard нажми **«Старт в VR (очки)»**.
3. Размести телефон в очках и дождись окончания обратного отсчёта.
4. Наводи центральный прицел на точку карты или панораму и нажимай на экран/кнопку очков.
5. Для обычного просмотра используй **«Без очков (мышь / гироскоп)»**.

### Если изображения двоятся

На стартовом экране есть ползунок **«Сближение изображений VR»**. Меняй значение небольшими шагами, пока изображения не начнут комфортно совмещаться. Значение `0` возвращает исходную настройку.

Результат зависит от расстояния между линзами, положения телефона и конкретной модели очков. Если изображение вызывает дискомфорт, прекрати просмотр и уменьши настройку или снизь время использования.

### Если не работает гироскоп

1. Открой сайт по HTTPS.
2. Используй актуальный Chrome на Android или Safari на iOS.
3. Нажми **«Проверить датчики»** на стартовом экране.
4. В течение 10 секунд медленно поверни телефон.
5. Проверь, меняются ли значения `α`, `β` и `γ` и есть ли события `Абсолютная` или `Движение`.
6. Если обычные события ориентации не приходят, приложение автоматически использует абсолютную ориентацию.

Некоторые Android-устройства передают датчики в системные приложения, но ограничивают или иначе формируют события для браузера. В таком случае диагностика помогает отличить проблему страницы от особенностей прошивки или Chrome.

## Конфигурация

В начале `index.html` находятся основные настройки:

- `TOKEN` — Access Token Mapillary;
- `IMG` — поле изображения Mapillary (`thumb_2048_url` или более тяжёлый `thumb_original_url`);
- `CAMH` — условная высота камеры для расчёта перехода к следующей панораме;
- `S` — размер внутреннего canvas карты.

### Важно о токене Mapillary

Страница работает полностью в браузере, поэтому токен, записанный в `index.html`, виден пользователям. Для публичного демо используй токен с ограниченными правами и лимитами. Для production-сервиса запросы к Mapillary лучше выполнять через серверный proxy с безопасным хранением секрета.

## Тесты

Тесты проверяют:

- запрос разрешения и повторную попытку;
- обработку отсутствующих и некорректных показаний;
- переключение между обычной и абсолютной ориентацией;
- поворот камеры и компенсацию угла экрана;
- зоны крестика и кнопок масштаба карты;
- синтаксическую корректность HTML-скрипта.

Запуск:

```bash
node --test tests/orientation.test.cjs
```

## Технологии

- HTML, CSS и JavaScript без фреймворка;
- [Three.js r128](https://threejs.org/);
- [Mapillary Graph API](https://www.mapillary.com/developer/api-documentation/);
- [OpenStreetMap](https://www.openstreetmap.org/) и Nominatim;
- Device Orientation / Device Motion API браузера.

## Ограничения

- панорамы Mapillary обычно являются моноскопическими, поэтому настоящий стереоскопический рельеф из одной фотографии не создаётся;
- комфорт и правильное совмещение изображений зависят от конкретных очков Cardboard;
- точность компаса и устойчивость ориентации зависят от телефона, магнитных помех, прошивки и браузера;
- для проверки датчиков на мобильном устройстве необходим защищённый контекст HTTPS;
- приложение рассчитано на браузерный просмотр и не является отдельным нативным приложением Google Cardboard.

Код проекта использует внешние сервисы Mapillary и OpenStreetMap. Соблюдай условия их использования, требования к атрибуции и ограничения API при публикации проекта.
